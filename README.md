About the Game

I started developing this game little by little during my classes at school. The project was inspired by my interest in Five Nights at Freddy’s (FNaF) and, more specifically, by how Scott Cawthon originally created the game using a relatively simple approach.

For the first day of development, I tried recreating the game in Clickteam Fusion, aiming to follow the original FNaF development style as closely as possible. However, I quickly realized that the software was difficult to work with and felt outdated for what I wanted to achieve. Because of that, I decided to move the project to Godot, which meant learning the engine and its workflow from scratch.

One of the biggest challenges was trying to make the game look 3D while primarily using PNG images. Creating the illusion of depth, movement, and interaction with 2D assets turned out to be surprisingly demanding, especially as a solo developer.

On top of that, I was developing the game while dealing with schoolwork, classes, and other responsibilities. Because of the limited time I had available, I wasn't able to finish the entire game.

For the final cut, I was only able to complete the main menu and the initial framework of the game. Even though it remains unfinished, this project was a valuable learning experience and gave me a much better understanding of game development, Godot, 2D asset manipulation, and the challenges of developing a game entirely on my own.

This project is ultimately a snapshot of what I was able to create bit by bit between classes and schoolwork, and I hope to return to these ideas and improve them in the future.
